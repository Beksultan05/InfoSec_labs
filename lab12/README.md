To complete this task, "Task: Try to discover attacks where the attacker can add some useful information about the victim (name, surname, date of birth), which are then combined in various ways," I pre-set up and launched the servers and used Hydra to perform the attack according to the instructions. I then created a first name, year of birth, and last name and entered this data into a script that would generate random passwords from these variables.
I took a random password from the generated ones and replaced the old password with it, then tried the attack again and was successful. This test demonstrates that using personal data for login and password is unsafe, as an attacker can easily create tens of thousands of different variations of these passwords for an attack.
